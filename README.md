# Vasyuki Landing — Клуб Четырёх Коней

Адаптивный лендинг по мотивам романа «12 стульев» (международный шахматный турнир в Васюках). Свёрстан вручную на чистом стеке **HTML + CSS + JavaScript** без фреймворков и UI-библиотек. Сборка — через **Vite**.

## Стек

- HTML5, семантическая разметка
- Vanilla CSS (CSS Variables, Grid, Flexbox, `clamp()`, медиазапросы)
- Vanilla JavaScript (ES Modules, `IntersectionObserver`)
- Vite — dev-server, бандлинг, prod-сборка

## Возможности

- **Pixel-perfect** реализация макета из Figma
- Полностью **адаптивный** дизайн от 320px до 1920px+ без горизонтального скролла и наезжающего текста
- Контент **не дублируется** между мобильной и десктопной версиями
- **Бегущая строка** (две, сверху и снизу) с бесшовным циклом
- **Якорные кнопки** на стартовом экране ведут к соответствующим секциям
- **Карусель участников** — зацикленная, автоматически переключается раз в 4 секунды; поддерживает свайпы и кнопки, ставится на паузу при наведении/фокусе/смене вкладки
- **Карусель этапов** — без автопрокрутки, без зацикленности; на десктопе превращается в коллаж-сетку, на мобильном — горизонтальная карусель со свайпами и кнопками
- Дополнительные **scroll-reveal анимации** и анимация летящего самолёта в секции этапов

## Структура

```
.
├── index.html              # Главная разметка лендинга
├── public/assets/          # Изображения и иконки (svg, jpg, png)
├── src/
│   ├── main.js             # Точка входа: инициализация модулей
│   ├── styles/main.css     # Все стили (токены, базовые, компоненты, медиа)
│   └── scripts/
│       ├── data.js                     # Данные участников
│       ├── render-participants.js      # Рендер карточек участников
│       ├── marquee.js                  # Бесконечная бегущая строка
│       ├── participants-carousel.js    # Авто-карусель участников (4s, looped)
│       ├── stages-carousel.js          # Ручная карусель этапов (manual)
│       └── reveal.js                   # Scroll-reveal анимации
├── vite.config.js
├── package.json
└── README.md
```

## Запуск

```bash
pnpm install        # либо npm install / yarn
pnpm run dev        # dev-сервер: http://localhost:5173/
pnpm run build      # prod-сборка → dist/
pnpm run preview    # предпросмотр сборки
```

## Заметки

- Все хедлайны защищены от переполнения через `overflow-wrap: break-word`, грид-контейнеры используют `minmax(0, 1fr)` чтобы текст корректно переносился на узких экранах.
- Шрифты: **Merriweather** (заголовки) и **Golos Text** (текст), подключаются через Google Fonts.
- SVG-логотип инлайновый — без сетевого запроса.
- Производственный бандл: ~14 КБ HTML, ~18 КБ CSS, ~10 КБ JS (около 12 КБ gzip итого).
